# 日文學習助手

貼上日文 → 自動分詞、標出動詞／形容詞的原型與變化、逐字翻譯、段落翻譯。

## 怎麼開啟

**方法一（建議）**：雙擊 `啟動.bat`，瀏覽器會自動打開 <http://localhost:8321/>。
關掉那個黑色視窗就等於關掉伺服器。

**方法二**：直接雙擊 `index.html`。多數情況可用，但少數瀏覽器會擋跨網域載入詞典，
這時改用方法一即可。

第一次開啟會從 CDN 下載約 15MB 的日文詞典（kuromoji IPADIC），會等十幾秒；
之後瀏覽器會快取，開啟就很快。

## 部署到 GitHub Pages

這是純靜態網站，放上去就能跑。這個資料夾已經是一個 git repo 並完成第一次 commit。

1. 到 <https://github.com/new> 建一個 repo，名稱建議 `jp-parser`，**不要**勾選任何
   「Add README / .gitignore / license」（否則會跟本地的 commit 衝突）。
2. 在這個資料夾執行（把 `<你的帳號>` 換成你的 GitHub 帳號）：

   ```
   git remote add origin https://github.com/<你的帳號>/jp-parser.git
   git push -u origin main
   ```

3. repo 頁面 → **Settings → Pages** → Source 選 `Deploy from a branch`，
   branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 等一兩分鐘，網址是 `https://<你的帳號>.github.io/jp-parser/`。

之後改了字典要更新線上版，就 `git add -A && git commit -m "加單字" && git push`。

**不能部署成 claude.ai 的 Artifact**：Artifact 有嚴格的 CSP，會擋掉所有外部主機的請求，
kuromoji 的 CDN 腳本和 17MB 詞典都載不進來，等於整個工具失效。

## 功能

| 功能 | 說明 |
|---|---|
| 斷詞 | 把連在一起的日文切成一個個詞塊，用顏色區分詞性（動詞綠、形容詞橘、名詞藍、助詞灰） |
| 假名注音 | 含漢字的詞上方標平假名讀音 |
| 原型還原 | `行きました → 行く`、`美味しかった → 美味しい`、`静かだった → 静か`，詞塊下方直接顯示藍色「原型」標籤 |
| 活用表 | 點任一詞塊，右側面板列出該動詞／形容詞的 15 種變化（ます形、て形、た形、ない形、可能、受身、使役、意向、條件、命令…），並把「目前這個句子用的是哪一形」用藍底標出來 |
| 變化來源拆解 | `待たされました` 會拆成 待たす＋れる（被動）＋ます（禮貌）＋た（過去），每個都有中文說明 |
| 逐字翻譯 | 每個詞塊下方直接顯示中文意思 |
| 段落翻譯 | 每段下方給整段的中文翻譯 |
| 單字表 | 每段可展開表格：單字／讀音／原型／詞性／中文 |
| 發音 | 單字、原型、活用表的每一形、整個段落都能唸出來，見下一節 |

## 發音

用瀏覽器內建的日文語音（Web Speech API），**離線可用、不需要金鑰、沒有次數限制**。

上方三項都可以調，調完會記在瀏覽器裡，下次開啟自動沿用：

| 設定 | 範圍 | 說明 |
|---|---|---|
| 語音包 | Haruka／Ichiro／Sayaka／Ayumi | 這台電腦裝的四個日文語音，Ichiro 是男聲 |
| 語速 | 0.4×–1.5× | 預設 0.9×。聽寫練習可以拉到 0.6× |
| 音量 | 0%–100% | 預設 100%。拉到 0 等於靜音 |

旁邊的**試聽**鈕會唸一句固定的日文，方便邊調邊聽；改語音包或放開滑桿時也會自動試聽一次。
**停止朗讀**可以中斷正在唸的段落。

哪裡可以聽：

- **點任何一個詞塊** → 直接唸（可用「點單字時發音」關掉）
- **段落標題旁的喇叭鈕** → 唸整段；再按一次停止
- **詳細面板** → 詞形和原型各有一個喇叭鈕
- **活用表的任一行** → 點下去唸那一形，適合拿來跟著唸一輪
- **單字表的任一列** → 點下去唸那個字

**單字發音用的是假名不是漢字**，這點很重要：`行った` 直接丟給語音引擎可能被唸成「おこなった」，
但工具知道它的原型是 `行く`，所以送出去的是 `いった`。助詞也一樣，`は` 會唸成「わ」、
`へ` 會唸成「え」——用的是 kuromoji 的 `pronunciation` 欄位而不是 `reading`。

活用表也因此多了一行假名注音（`行った` 下面標 `いった`）。

段落朗讀則是直接送原文，讓語音引擎自己抓語調，聽起來比較自然。

如果上方那排發音控制項變灰，表示系統沒裝日文語音：
Windows 到「設定 → 時間與語言 → 語言」新增日文並安裝語音套件，重開瀏覽器即可。

## 翻譯來源

1. **內建詞典**（離線）：約 1000 個常用單字 + 100 條助詞／助動詞文法說明 + 66 個接頭尾詞。
   助詞、助動詞的說明是手寫的，比機器翻譯準確得多——這是查字典最查不到的部分。
2. **漢字對照**：查不到的漢字詞會做「新字體 → 正體字」轉換（例：`駅 → 驛`、`図書館 → 圖書館`）。
3. **線上翻譯**：以上都查不到時，才呼叫免費的 MyMemory API。段落翻譯也走這裡。
   可以用勾選框關掉，關掉後整個工具完全離線運作（除了第一次載入詞典）。

線上翻譯查過的字會存在瀏覽器裡，同一個字不會重複查。

## 瀏覽器支援

桌面版 Chrome / Edge / Firefox / Safari，以及 iOS Safari、Android Chrome 都可以。

程式碼刻意避開了 regex lookbehind（`(?<=...)`）這類較新的語法。
原因值得記一筆：**regex 字面量的語法錯誤發生在「解析期」而不是「執行期」**，
所以只要檔案裡有一個 Safari 不認得的 lookbehind，整個 `.js` 都不會執行——
畫面和樣式完全正常，但每個按鈕都沒反應，而且 console 只有一行看不出所以然的
SyntaxError。這在桌面 Chrome 上測不出來，只有實際拿舊 Safari 開才會現形。

如果之後要加程式碼，避開 lookbehind、`?.`、`??`、`matchAll`、`replaceAll` 這幾個，
就能維持相容性。頁面已內建 `window.onerror` 攔截，任何載入錯誤都會直接顯示在
標題下方的狀態列，不會再變成無聲的失效。

## 已知限制

- 免費 MyMemory API 有每日額度，額度用完段落翻譯會顯示失敗，但斷詞和原型分析不受影響。
- 機器翻譯回來的中文有時是簡體字。
- 斷詞用的是 IPADIC 詞典，遇到人名、新詞、網路用語可能切得不理想。
- 同形異音詞（例：`十分` 可能是「十分鐘」或「充分」）只能靠上下文，工具會挑詞典裡的一種。

## 想加字典

打開 `js/dict.js`，照現有格式加就好：

- `JDICT`：一般單字，key 用**辭書形（原型）**，例：`"諦める":"放棄"`
- `JGRAM`：助詞／助動詞，可以寫用法說明，例：`"のに":{zh:"明明…卻…",note:"逆接，帶不滿或意外。"}`
- `JAFFIX`：接頭詞、接尾詞、量詞，例：`"駅":"…車站"`

存檔後重新整理網頁即可生效（本機檔案帶時間戳載入，不會被瀏覽器快取擋住）。
